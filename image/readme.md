将镜像文件放入此目录，并在 `image.json` 中配置后，自动重装将优先使用此处镜像。

## image.json 字段说明

| 字段 | 说明 |
|---|---|
| `file` | 此目录下的镜像文件名（如 `"win10.esd"`） |
| `index` | 要安装的版本索引，正数为固定索引，`-1` 为自动选择 |
| `version` | 目标系统版本：`"7"`、`"10"`、`"11"` |
| `arch` | 目标架构：`"64"`、`"32"`，空字符串表示不限制 |
| `verify` | 是否校验镜像结构，默认 `true`（校验），`false` 表示跳过校验直接使用 |
