# data_probe

`data_probe` 是规则 JSON 解析测试工具。
它帮助你验证：某个规则文件在项目里是否能被正确解析成业务数据。

## 它会展示什么

- 解析摘要（基础字段、条目数量等）
- `RuleItem` 明细
- `WinPEImg` 明细

这对排查“规则文件写法对不对、字段是否生效”很直接。

## 怎么用

1. 运行 `data_probe.exe`。
2. 点击“选择文件”，选中要测试的 JSON。
3. 点击“开始解析”。
4. 查看中部摘要与底部两栏明细结果。

## 适合什么时候用

- 新增或修改规则 JSON 后做快速自检
- 对比不同规则文件的解析差异
- 定位某个字段为何没有按预期生效

## 构建

- 双击 [build.bat]
- 或命令行执行：

```bat
test\data_probe\build.bat
```
