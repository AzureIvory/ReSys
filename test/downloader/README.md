# downloader

`downloader` 是一个下载流程测试工具，用于验证项目里的下载能力是否正常。
它直接复用主程序的下载实现，支持两种来源：

- `HTTP/HTTPS` 直链
- `BT magnet` 链接

## 适合什么时候用

- 你想快速确认“当前机器能不能正常下载镜像”
- 你要排查下载速度、进度显示、链接可用性
- 你要验证直链和 BT 在同一环境下的表现

## 怎么用

1. 运行 `downloader.exe`（或双击打开）。
2. 在“镜像链接”输入下载链接。
3. 在“下载目录”输入一个目录路径。
4. 点击“开始下载”。

程序会自动判断链接类型并开始下载。

## 重要说明

- 下载目录只填“目录”，不要填文件名。
- 如果是直链，文件名会自动从链接中提取。
- 如果是 BT，目录会作为下载保存目录使用。

## 构建

- 双击 [build.bat]
- 或命令行执行：

```bat
test\downloader\build.bat
```
