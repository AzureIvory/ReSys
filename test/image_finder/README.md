# image_finder

`image_finder` 是本地镜像扫描与解析测试工具。
它用于验证本机能找到哪些安装镜像，以及镜像里的索引信息是否可读。

## 支持范围

- 扫描并识别本地 `ISO / WIM / ESD`
- 列表展示：文件名、识别到的系统、完整路径
- 选中镜像后自动解析索引
- `index` 使用组合框展示
- 其他详细信息用文本框展示（名称、版本、架构、标识、大小、描述等）

## 怎么用

1. 运行 `image_finder.exe`。
2. 点击“开始寻找”，等待扫描完成。
3. 在左侧列表点选任意镜像。
4. 在右侧查看索引与详细信息。

## 适合什么时候用

- 你要确认本机镜像扫描逻辑是否正常
- 你要检查某个 ISO/WIM/ESD 是否能被正确解析
- 你要快速查看镜像索引与系统版本对应关系

## 构建

- 双击 [build.bat]
- 或命令行执行：

```bat
test\image_finder\build.bat
```
